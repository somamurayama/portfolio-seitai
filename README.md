# ほぐし整体 ゆるり（ポートフォリオ用LP）

新潟市内にある**架空の**整体院のランディングページです。
HTML / CSS / 素のJavaScript のみで作っています（ビルド不要）。

## フォルダ構成

```
portfolio-seitai/
├─ index.html        … ページ本体（10セクション）
├─ css/style.css     … スタイル（スマホ優先・768px / 1024px で切り替え）
├─ js/main.js        … メニュー、フェードイン、お悩みチェック、FAQ、LINEデモ、固定CTA
├─ images/favicon.svg
└─ vercel.json       … ヘッダー設定（CSS/JSは長期キャッシュしない）
```

## ローカルで見る

`index.html` をブラウザで開くだけで表示できます。

## 公開

GitHub のリポジトリを Vercel に Import（Framework Preset: Other、Build 設定は空のまま）。
`main` に push すると自動で再デプロイされます。

## 表現について

- 整体は医療行為ではないため、「治る」「治療」「改善を保証」など効果を断定・保証する表現は使っていません。
- お客様の声には「※個人の感想です」と注記しています。
- 初回限定価格は、通常価格（6,600円）とあわせて表示しています。

## メモ

- LINE予約ボタンはデモ用のダイアログを開きます。実運用では公式LINEの友だち追加URLへのリンクに差し替えてください（`js/main.js` のコメント参照）。
- 写真は Unsplash のフリー素材を URL で読み込んでいます。院長の写真もフリー素材のイメージです。
- 電話番号・住所・院長名・お客様の声はすべて架空です。
